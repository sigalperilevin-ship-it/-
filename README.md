# עידן היופי — מערכת זימון תורים וניהול

קליניקה לטיפולי אסתטיקה מתקדמת.

מערכת דמו אינטראקטיבית: אזור לקוחה (שאלון התאמה, אישור אישי, זימון תור ביומן, פדיקור רפואי, הזמנת מוצרי דרמלוסופי) ואזור ניהול (סקירת יום, כרטיסי לקוחות, חבילות ותשלומים, התראות).

## הרצה
פשוט לפתוח את `index.html` בדפדפן. אין צורך בהתקנה.

## פרסום ב-GitHub Pages
Settings → Pages → Branch: `main` / root → Save.
